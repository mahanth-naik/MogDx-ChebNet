# MogDx with ChebNet

MogDx is a healthcare disease prediction project that explores
Machine Learning and Graph Neural Networks (GNNs) for analyzing
structured healthcare data.

The project integrates Chebyshev Graph Neural Networks (ChebNet)
to explore graph-based learning for disease prediction and
relational data analysis.

## Features

- Disease prediction using Machine Learning and Graph Neural Networks
- ChebNet-based graph learning
- Healthcare data preprocessing and feature engineering
- Data visualization using Matplotlib
- Healthcare dataset analysis
- Prediction workflow and model evaluation
- Modular project structure

## Tech Stack

- Python
- ChebNet
- Graph Neural Networks (GNN)
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Project Objectives

- Explore Graph Neural Networks for healthcare applications
- Investigate ChebNet for graph-based disease prediction
- Build a preprocessing and feature-engineering pipeline
- Analyze and visualize healthcare datasets
- Evaluate graph-based approaches for disease prediction
